# Plans

Tracked plans for changes that span several steps or pull requests.

- One Markdown file per plan, named after the change, for example `Plans/AddNotifications.md`.
- A plan lists its goal, the steps, how each step is verified, and decisions with their reasons.
- When a plan is done, record the merge commit(s) and the verification in the plan, then mark it complete.
- Scratch notes and drafts go in `Plans.local/`, which git ignores.

Older retained plans, if any, live in `docs/plans/`.
