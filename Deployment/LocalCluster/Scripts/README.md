# LocalCluster Scripts

Top-level scripts provide LocalCluster setup, operations and validation commands.

- `Component/` holds internal helpers.
- `Component/lib/` holds Python helpers used by scripts, CI and the deployment audit.
- `Component/node-db/` holds backup and restore scripts copied to database nodes.
- `Tests/` holds script fixtures.

Start with the [LocalCluster guide](../HowToDeployLocalCluster.md). Shared implementation lives in [Deployment Common](../../Common/README.md).
